CONCEPTO

¿Qué es Bootstrap y por qué usarlo?

Un atajo, no magia

Bootstrap es una colección de CSS ya escrito (y un poco de JavaScript) que incluye una rejilla de 12 columnas, decenas de clases utilitarias y componentes completos.

Por debajo sigue siendo CSS

Su rejilla usa Flexbox y sus breakpoints son media queries. Todo lo de las sesiones 18 y 19 está ahí dentro.

Cuándo conviene

Prototipos rápidos, paneles administrativos, equipos grandes y proyectos con fecha corta.

Cuándo no

Diseños muy personalizados o páginas de una sola sección: cargas más CSS del que usas.

Aspecto Tu CSS (Sesión 19) Bootstrap (Sesión 20)
Velocidad Escribes cada regla Casi todo ya existe
Control Total: es tu código Hay que respetar sus clases
Peso Solo lo necesario ~230 KB de CSS completo
Aprendizaje Entiendes el porqué Memorizas nombres de clases
Mantenimiento Tú decides la estructura Estándar conocido por todos
💡 Lo importante: quien sabe CSS usa Bootstrap con criterio; quien no sabe CSS queda atrapado cuando el resultado no es el esperado. Por eso dimos Grid y Flexbox primero.

TEMA 1

Instalación: dos etiquetas y listo

CDN

La forma más rápida es el CDN: el CSS se enlaza en el <head> y el JavaScript, si lo necesitas, antes de cerrar el <body>.

1. El CSS va primero

Siempre en el <head>, antes de tu propia hoja de estilos.

2. El JS, al final

Solo hace falta para menús desplegables, modales y alertas que se cierran.

3. Verifica con un botón

Si btn btn-primary se ve azul, Bootstrap cargó bien.

⚠️ Sin internet, el CDN no carga. Para entregar el proyecto, descarga los archivos en css/ y js/ y usa rutas relativas.
index.html
<!DOCTYPE html>
<html lang="es">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
/* 1. Bootstrap (CDN) */
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">
/* 2. Tu CSS, siempre después */
<link href="css/estilos.css" rel="stylesheet">
</head>
<body>
…contenido…
/* 3. JS antes de cerrar el body */
<script src=".../bootstrap.bundle.min.js"></script>
</body>
Tema 1: instalar sin descargar nada <link> en head · <script> al final
TEMA 2

La rejilla de 12 columnas

container · row · col

Toda la página se imagina dividida en 12 columnas invisibles. Tú solo decides cuántas ocupa cada elemento y la suma de una fila debe dar 12.

.container

Centra el contenido y le da márgenes laterales.

.row

Crea la fila y activa la rejilla (usa Flexbox).

.col-*

Define cuántas de las 12 columnas ocupa el elemento.

💡 Regla de oro: si la suma pasa de 12, los elementos que sobran bajan a la siguiente línea.

TEMA 3

Breakpoints: el tamaño va en la clase

mobile first
Clase Aplica desde Se ve en
col-12 0 px (sin prefijo) Celular
col-sm-6 ≥ 576 px Celular horizontal
col-md-6 ≥ 768 px Tablet
col-lg-4 ≥ 992 px Laptop
col-xl-3 ≥ 1200 px Monitor
col-xxl-2 ≥ 1400 px Pantallas grandes
Es mobile first: Bootstrap usa min-width, así que col-md-6 aplica desde 768 px hacia arriba. En la Sesión 19 usamos max-width (de mayor a menor); el resultado es el mismo, cambia el sentido.
Una clase por cada tamaño
/* 1 · 2 · 4 columnas según el ancho */
<div class="col-12 col-sm-6 col-lg-3">
/* se lee así */
col-12 /* celular: 100% */
col-sm-6 /* desde 576px: mitad */
col-lg-3 /* desde 992px: cuarto */
⚠️ No hace falta escribir media queries: el prefijo sm, md, lg ya contiene la suya.

Antes (tu CSS) · Después (Bootstrap)
/* 3 reglas propias */
.caja { padding: 1.5rem; }
.caja { margin-top: 1rem; }
.caja { border-radius: .5rem; }
/* 1 línea de HTML */
<div class="p-4 mt-3 rounded-3 bg-white shadow-sm">
💡 Consecuencia: el HTML se llena de clases. Es normal: se lee de izquierda a derecha como una receta. La ventaja es que no escribes CSS para cada detalle.
⚠️ No mezcles sistemas: si usas p-4, no le pongas además padding en tu CSS sin saber cuál gana. El CSS propio cargado después tiene prioridad.

TEMA 5

Componentes base: botones y alertas

btn · alert

Un componente es un bloque ya diseñado: tú solo eliges la variante (color) y el tamaño.

Botones
/* clase base + variante + tamaño */
btn btn-primary
btn btn-outline-secondary
btn btn-success btn-lg
Alertas
alert alert-success
alert alert-warning
alert alert-danger
💡 Colores con significado: en una clínica, success para “cita confirmada”, warning para “confirma tu asistencia” y danger para “no disponible”.

TEMA 6 · TALLER

Integra Bootstrap en tu landing

Partimos de la landing del centro odontológico (Sesión 19) y reemplazamos la estructura por la de Bootstrap, sin perder el diseño.

1. Enlaza el CSS de Bootstrap antes de tu hoja de estilos.
2. Cambia tu <header> por un navbar navbar-expand-lg.
3. La galería de servicios: container > row g-4 > col-12 col-md-6 col-lg-4.
4. Botones: btn btn-primary. Aviso de cita: alert alert-success.
5. Revisa qué cambió y qué se rompió: ahí está el aprendizaje.
⚠️ Si tu CSS propio “no se aplica”, revisa el orden: Bootstrap primero, tu CSS después.
Resultado en Vivo 
<!-- 1. En el head, antes de tu CSS -->
<link href="...bootstrap.min.css" rel="stylesheet">
<link href="css/estilos.css" rel="stylesheet">

<!-- 2. El menú -->
<nav class="navbar navbar-expand-lg bg-dark">
  <div class="container">
    <a class="navbar-brand text-white">Sonrisa Viva</a>
    <button class="btn btn-warning btn-sm ms-auto">
      Reservar
    </button>
  </div>
</nav>

<!-- 3. La galería de servicios -->
<div class="container py-4">
  <div class="row g-3">
    <div class="col-12 col-md-4">
      <div class="p-3 border rounded-3">Limpieza</div>
    </div>

  </div>
</div>

TU RESUMEN DE BOLSILLO
  • • CSS en head + JS al final → instalación por CDN.
  • • container > row > col → la rejilla de 12.
  • • col-12 col-md-6 col-lg-3 → responsive sin media queries.
  • • m-*, p-*, gap-* → espaciados en la clase.
  • • d-flex → tu Flexbox de siempre, con otro nombre.
  • • btn y alert → componentes con variantes de color.
